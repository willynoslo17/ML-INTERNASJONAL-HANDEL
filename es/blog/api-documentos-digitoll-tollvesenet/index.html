Envío anticipado de documentos por API a Tollvesenet

Introducción

Tollvesenet (la aduana noruega) permite enviar por anticipado la documentación de apoyo a la declaración mediante una API. Según la página oficial actualizada, se pueden transmitir facturas, permisos, fletes, certificados de origen o cartas de porte para que estén disponibles antes de que la mercancía llegue a la frontera. La propia aduana describe la solución como un piloto.

Este artículo explica el beneficio conceptual. No presenta la API como obligatoria ni como un servicio de ML Internasjonal Handel.

Qué permite la API de documentos

La API permite el envío no solicitado y anticipado de documentos de apoyo, así como el envío posterior si la aduana los solicita. Los documentos se vinculan a la declaración en el sistema TVINN.

Documentos que pueden enviarse

Entre los ejemplos que cita la aduana figuran facturas, permisos, facturas de flete, certificados de origen y cartas de porte. La solución admite formatos habituales de archivo. El envío anticipado hace que la documentación esté disponible para los funcionarios cuando procesan la declaración.

Beneficio conceptual del envío anticipado

Al disponer de los documentos antes de la llegada, se reduce la necesidad de contactos posteriores para controles documentales y disminuye el riesgo de retrasos en el procesamiento.

Disponibilidad antes de la frontera

La mercancía puede estar sujeta a notificación Digitoll y a declaración previa o en el momento del cruce. Tener la documentación de apoyo ya cargada facilita la coherencia entre lo declarado y lo aportado. No sustituye la exactitud de los datos maestros ni la responsabilidad del declarante.

Carácter de solución piloto

Tollvesenet indica que la solución se ha desarrollado a partir de consultas con el sector y se encuentra en fase piloto para verificar su rendimiento. Recomienda su uso, especialmente a quienes declaran en Digitoll hacia determinadas unidades de despacho, pero no la declara obligatoria.

Descargo

Texto informativo basado en la información publicada por Tollvesenet (https://www.toll.no/en/corporate/import/api-for-submitting-documentation-for-declaration-in-advance). No presenta la API como obligatoria ni como producto de ML Internasjonal Handel. Consulte las especificaciones técnicas oficiales para detalles de implementación.

¿La API es obligatoria?
No. La aduana la describe como una solución en fase piloto que recomienda utilizar.
¿Qué documentos se pueden enviar?
Entre otros, facturas, permisos, fletes, certificados de origen o cartas de porte.
¿Sustituye a la declaración?
No. Complementa la declaración al hacer disponibles los documentos de apoyo con antelación.
