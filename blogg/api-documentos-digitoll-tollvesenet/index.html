Forhåndssending av dokumenter via API til Tollvesenet

Introducción

Tollvesenet tillater å sende støttedokumentasjon til deklarasjonen på forhånd via en API. Ifølge den oppdaterte offisielle siden kan fakturaer, tillatelser, frakt, opprinnelsessertifikater eller fraktbrev overføres slik at de er tilgjengelige før varene når grensen. Tollvesenet selv beskriver løsningen som en pilot.

Denne artikkelen forklarer den konseptuelle fordelen. Den presenterer ikke API-en som obligatorisk eller som en tjeneste fra ML Internasjonal Handel.

Hva API-en for dokumenter tillater

API-en tillater uspurt og forhåndssending av støttedokumenter, samt senere sending dersom tollvesenet ber om dem. Dokumentene knyttes til deklarasjonen i TVINN-systemet.

Dokumenter som kan sendes

Blant eksemplene tollvesenet nevner er fakturaer, tillatelser, fraktfakturaer, opprinnelsessertifikater og fraktbrev. Løsningen støtter vanlige filformater. Forhåndssendingen gjør at dokumentasjonen er tilgjengelig for tjenestemennene når de behandler deklarasjonen.

Konseptuell fordel ved forhåndssending

Ved å ha dokumentene tilgjengelige før ankomst reduseres behovet for senere kontakt for dokumentkontroll, og risikoen for forsinkelser i behandlingen minskes.

Tilgjengelighet før grensen

Varene kan være underlagt Digitoll-varsling og forhåndsdeklarasjon eller deklarasjon ved kryssing. Å ha støttedokumentasjonen allerede lastet opp letter samsvaret mellom det som er deklarert og det som er levert. Det erstatter ikke nøyaktigheten av masterdataene eller deklarantens ansvar.

Karakter av pilotløsning

Tollvesenet angir at løsningen er utviklet basert på konsultasjoner med næringen og befinner seg i pilotfase for å verifisere ytelsen. Det anbefaler bruken, spesielt for de som deklarerer i Digitoll mot bestemte ekspedisjonsenheter, men erklærer den ikke som obligatorisk.

Descargo

Informativ tekst basert på informasjonen publisert av Tollvesenet (https://www.toll.no/en/corporate/import/api-for-submitting-documentation-for-declaration-in-advance). Presenterer ikke API-en som obligatorisk eller som et produkt fra ML Internasjonal Handel. Konsulter de offisielle tekniske spesifikasjonene for implementeringsdetaljer.

Er API-en obligatorisk?
Nei. Tollvesenet beskriver den som en løsning i pilotfase som det anbefales å bruke.
Hvilke dokumenter kan sendes?
Blant annet fakturaer, tillatelser, frakt, opprinnelsessertifikater eller fraktbrev.
Erstatter den deklarasjonen?
Nei. Den utfyller deklarasjonen ved å gjøre støttedokumentene tilgjengelige på forhånd.
