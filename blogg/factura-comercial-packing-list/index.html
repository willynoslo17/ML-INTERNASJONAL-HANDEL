Handelsfaktura, packing list og tollmessig samsvar

Introducción

Handelsfakturaen og packing list er sentrale dokumenter i enhver import- eller eksportoperasjon. De må være i samsvar med hverandre og med tolldeklarasjonen. Denne artikkelen beskriver i generelle termer hvilken informasjon hver vanligvis inneholder og hvorfor datasamsvar er viktig.

Den tilbyr ikke nedlastbare maler eller skjemaer som pretenderer å være offisielle.

Funksjonen til handelsfakturaen

Handelsfakturaen dokumenterer kjøps- og salgstransaksjonen: parter, varebeskrivelse, mengder, pris, valuta, Incoterm og betalingsvilkår. Den tjener som grunnlag for tollverdi og andre kontroller.

Data som vanligvis inngår

I tillegg til partenes data og beskrivelsen inkluderer den vanligvis den deklarerte opprinnelsen, ordreferanser og, når det er aktuelt, HS-koden som partene bruker. Disse elementene må kunne avstemmes med packing list og med det som deklareres.

Funksjonen til packing list

Packing list detaljerer hvordan varene er emballert: antall kolli, innholdet i hvert, brutto- og nettovekt, og merking. Den letter fysisk inspeksjon og verifisering av mengder.

Forhold til kolli og mengder

De totale mengdene i packing list må stemme overens med de i fakturaen. Beskrivelsene må være kompatible. Enhver forskjell (for eksempel et ekstra kolli som ikke er fakturert eller en mer generisk beskrivelse) kan generere spørsmål.

Samsvar med tolldeklarasjonen

Tolldeklarasjonen henter data fra disse dokumentene og fra bedriftens masterdata: beskrivelse, mengder, statistisk verdi, Incoterm, opprinnelse og HS-kode. Samsvar mellom faktura, packing list, transportdokument og deklarasjon reduserer risikoen for ytterligere kontroller.

I norsk sammenheng gjør muligheten for å sende dokumenter på forhånd via Tollvesenets API det enda mer relevant at informasjonen er justert fra opprinnelsen. Godt vedlikeholdte masterdata (stabile beskrivelser, gjennomgåtte HS-koder, dokumentert opprinnelse) letter dette samsvaret.

Descargo

Informativ tekst. Den utgjør ikke en mal for faktura eller packing list eller tollrådgivning. Nøyaktigheten av deklarasjonen er deklarantens eller dens autoriserte representants ansvar. Konsulter offisielle og profesjonelle kilder.

Er handelsfakturaen den samme som den elektroniske skatteregnskapfakturaen?
Ikke nødvendigvis. Handelsfakturaen tjener handelstransaksjonen og toll; den elektroniske skatteregnskapfakturaen svarer til lokale regnskaps- og skatteregler.
Hva skjer ved avvik?
De kan generere henvendelser fra tollvesenet, forsinkelser eller behov for retting. Samsvar reduserer denne risikoen.
Erstatter packing list fakturaen?
Nei. Den utfyller fakturaen ved å detaljere innholdet i kolliene.
